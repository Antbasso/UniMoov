## Spécifique à Claude Code
- Pour une tâche qui touche plus de trois fichiers, commence par un plan court, puis exécute jalon par jalon (voir `docs/roadmap.md`).
- Lis les documents de `docs/` avec l'outil de lecture plutôt que de supposer leur contenu.
- Utilise des sous-agents pour les recherches larges dans le code, pas pour écrire du code en parallèle sur les mêmes fichiers.
