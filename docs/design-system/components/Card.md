Surface flottante d'Uni-Moov : fond `surface-raised`, rayon `radius-lg`, ombre `shadow-soft` (lueur violette).

- `um-card` : carte de contenu (titre `h3`, texte `body-sm` en `ink-muted`).
- `um-card--frame` : cadre `lavender` de 12 px autour d'un contenu blanc, comme le QR code de l'affiche. À réserver à un code ou une image à scanner ; le QR garde toujours un fond clair et un contraste maximal, même en thème sombre.

Le consommateur fournit le contenu. Une carte ne contient qu'une action principale. Pas de bordure de couleur sur un seul côté.
