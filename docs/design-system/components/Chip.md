Puce arrondie (`radius-pill`) pour une information courte : places libres, statut d'un trajet. La variante manuscrite « sticker » (`um-note`) reprend la pastille lavande inclinée de l'affiche.

- Puce neutre : fond `lavender`, texte `brand-strong`.
- Succès : fond `success-soft`, texte `success`. Erreur : fond `danger-soft`, texte `danger`. Le statut porte toujours un mot et une icône : jamais la couleur seule.
- Le sticker `note` (police Caveat, 26 px, `brand-strong` sur `lavender`, rotation de -4°) sert une seule fois par écran ou affiche, pour guider l'œil vers l'action (« Scanne le QR code »). Jamais pour du texte juridique ou long.

Le consommateur fournit le texte (une phrase courte, tutoiement) et l'icône de 16 px au trait de 2 px.
